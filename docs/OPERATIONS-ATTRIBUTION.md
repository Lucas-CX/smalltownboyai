# 运营归因与自测

自测先打开 https://smalltownboyai.video/?diagnostic=1 ，再在同一浏览器操作。
入口在 GA 初始化之前排除访问；Clarity 同样排除，后台标记诊断流程。
标记跨登录保留：当前标签页 sessionStorage，以及最长 24 小时的同站 Cookie。
管理员权限识别后也会开启诊断模式；识别前的首屏事件不能追溯撤回，因此管理员自测仍应从专用入口进入。
真实获客核查使用另一个未标记的浏览器环境，避免把诊断 Cookie 带入客户测试。
诊断标记只影响统计，不提供支付、生成或权限豁免。

## 推广链接

```sh
node scripts/campaign-link.mjs instagram social launch_20261014
node scripts/campaign-link.mjs youtube social launch_20261014 /smalltown-boy-sample
```

source=渠道、medium=渠道类型、campaign=活动。仅用小写字母、数字、下划线或连字符。
不要写姓名、邮箱、客户ID等个人信息；不要给站内导航加 UTM。
GA 已保留这三项以及合规的 content/term；后台仅记录前三项，取当前标签页首次带标签访问，跨登录返回保留。
后台数据是流程口径，不等于 GA 会话或独立人数；无法推断 Direct 的实际来源。
脚本只生成链接，不会自动发布内容或启动广告。

## 样片排障

样片失败事件携带浏览器类别、固定失败原因；重试与恢复分别记录。
不收集完整 UA、视频地址、图片内容或原始异常。
video_unsupported 是浏览器媒体错误分类，不能仅凭它断定视频编码有问题；先核对网络及实际播放。
