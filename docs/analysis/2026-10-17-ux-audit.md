## 优先级

- **P1：支付回跳异常恢复。** 验证中、到账成功、尚未确认、登录失效分开显示，提供查询状态与返回工作室，不鼓励重新付款。
- **P1：支付失败提示分类。** 区分余额读取失败、无法打开付款页、支付状态待核对，保留照片和原付款请求标识。
- **P1：付款后的生成引导。** 保留主动确认的安全边界，但让用户一眼看到钱已到账、还没开始生成、下一步怎么做。
- **P1：效果预期。** 购买处明确固定红围栏模板与实际音频，提供真正交付样片，减少与灵感视频混淆。
- **P2：压缩移动端路径。** 照片后直接套餐及单一主按钮，规格折叠，减少重复总价框；新用户主要看“次数”，旧积分仍可查。
- **P2：草稿与文件时限。** 草稿当前保留 30 分钟，支付或登录较久可能过期；过期时应明确“额度仍在，仅需重新选图”。文件保留从任务创建计时应重新评估。

## 建议的目标流程

看实际样片与起价 → 选择 A/B 照片 → 选择 1/3/5 次套餐（默认 3）→ 登录并继续 → 前往支付 → 服务端核验到账 → 明确显示剩余次数 → 用户主动点击生成 → 可离开的进度页 → 完成后下载。

已有余额用户：选照片 → 确认照片权限 → 使用 1 次生成，不再经过购买步骤。恢复草稿绝不能自动生成或扣费。
