# 本地生成流程改版验收

范围：仅本地，不提交、不部署，不进行真实支付或付费生成。

## 已验证

- 新草稿默认 3 次套餐；本地浏览器选 5 次、刷新后两张照片与 5 次选择仍保留。
- 恢复后授权复选框未勾选；隔离代理记录没有自动生成请求。
- 付款双击只发起一次购买请求；失败后手动重试沿用相同 requestKey 和 packId。
- 付款返回仅进行一次状态核对；后续手动查询才新增一次请求，无轮询。
- 未确认时工作室暂停付款与生成，提供重新查询、登录及帮助入口。
- 模拟 450 积分到账，显示使用 1 次、剩余 2 次；双击生成只发出一次生成请求，没有新增购买请求。
- 金额、归属、支付状态由服务端验证。重复支付回调与重复回跳核对使用原幂等入账逻辑。
- 手机端 390px 无横向溢出，用户原本照片和套餐选择保留。
