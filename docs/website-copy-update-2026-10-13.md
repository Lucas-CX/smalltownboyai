# 网站文案优化实施记录

日期：2026-10-13。本轮基于 `website-copy-audit-2026-10-13.md`，修改当前工作区，未提交 Git、推送或部署。

## 已实施

- 生成提交异常不再声称“未产生费用”，提示先查任务和积分，并展开任务列表、刷新状态。余额读取失败与浏览器草稿保存失败分别提示；余额不足仍进入原购买流程。
- 文件访问到期与关闭访问分别显示。进一步核对后发现，后端 `deleted` 状态先于物理清理写入，因此使用“文件访问已关闭”，不声称所有副本已彻底删除。可用任务在接口提供截止时间时显示下载期限。
- 付款后文案区分有效、已确认草稿与仅购买积分/草稿失效，明确返回同一标签页。
- 客户首页改为积分、我的视频、付款记录及帮助入口，删除免费订阅、API 数量、固定为零的使用量和搭建产品的模板内容。普通账户导航移除订阅与 API Keys；原直达路由保留，未删除底层业务模块。
- 付款状态、积分类型及日期按界面语言显示；注册与重置密码补中文长度校验，校验文本在页面渲染时解析语言，避免模块加载时固定语言。请求失败不直接展示底层英文错误。
- 首页简述直接说明输入、时长和输出；价格 FAQ 从共享套餐配置读取价格与积分，继续共用于页面、JSON-LD、发现文本。套餐文案统一按生成次数表达。
- 图库明确标为舞蹈灵感，与本站模板样片区分，没有恢复作者、平台或播放量信息。
- 中英文照片指南补充格式、20 MB、最低尺寸、比例、HEIC 条件与人物许可要求；制作教程统一下一步操作，购买指南改为购买前须知，样片限制缩短为清晰说明。
- 政策“我的视频”链接统一到 `/#orders`，保留语言本地化；文件期限统一为视频任务创建起算，区别于积分购买时间。
- About 明确本服务域名；Contact 按问题类型列出所需信息；退款页改为申请材料与核查流程，保留消费者权益说明。
